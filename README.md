AI Chat Assistant

A simple AI chat application built with Flask, HTML, CSS, and JavaScript. The project provides a clean chat interface and connects the frontend to a Flask backend for processing messages and AI responses.

Live Demo

Chat Assistant

Features

Clean and responsive chat interface

Flask backend

Separate HTML, CSS, and JavaScript files

Asynchronous messaging using JavaScript fetch()

AI API integration

Environment-variable based API key handling

Getting Started

Install Flask and the required dependencies, configure your API key as an environment variable, and run the Flask application locally.

Never commit your API key or other secrets to GitHub.
